# BNI Events — Agenda Networking

Site web statique présentant l'agenda de networking BNI.

## Aperçu

Ce dépôt héberge une page statique publiée via **GitHub Pages**.

## Structure

- `index.html` — page principale du site
- `README.md` — ce fichier

## Publication

Le site est publié automatiquement via GitHub Pages depuis la branche `main`.
Une fois activé, il sera accessible à l'adresse :

```
https://<votre-nom-utilisateur>.github.io/<nom-du-depot>/
```

## Modifier le site

1. Éditez `index.html`
2. Commitez les changements : `git commit -am "Mise à jour du site"`
3. Poussez : `git push`
4. GitHub Pages redéploie automatiquement en quelques secondes.
